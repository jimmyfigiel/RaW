# Roll and Write PWA

This is a static deployable PWA prototype for roll-and-write play support.

## Included features

- 3 white dice and 3 black dice
- tap any die to reroll it
- Roll button to reroll all dice
- Number tool
- Red dot tool
- O/X tool
- Undo
- Local save in browser storage
- Install prompt support
- Basic offline caching through a service worker

## Files

- `index.html`
- `styles.css`
- `app.js`
- `manifest.json`
- `service-worker.js`
- `icon-192.png`
- `icon-512.png`

## Upload to GitHub

Create a new GitHub repository, then upload all files in this folder to the repo root.

## Deploy

Deploy the repo as a static site with Vercel, Netlify, or GitHub Pages.

## Notes

This bundle is intentionally static and has no build step.
It is a deployable prototype based on the working preview.
A later version can swap the sample board for PDF loading and annotation.
